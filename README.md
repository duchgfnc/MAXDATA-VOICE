# MAXDATA-VOICE · 车外喊话与锁车音效库

供 MAXDATA 车机 App「在线音效」功能拉取的公开音频库。App 通过 jsDelivr 镜像 +
`raw.githubusercontent.com` 多源读取本仓库的 `manifest*.json`，按需下载单个 WAV 到本地缓存，
下载后按清单里的 `sha256` 与字节数校验，不符即丢弃。

## 目录

```
manifest.json        # 当前清单（App 读这个）
manifest-vN.json     # 每个版本的独立清单（绕过 CDN 旧缓存，App 会探测最新版本号）
talk/                # 车外喊话 WAV
lock/                # 锁车音效 WAV
```

## 清单格式

```json
{
  "version": 4,
  "note": "…",
  "format": "wav pcm_s16le 16000Hz mono",
  "clips": [
    {
      "id": "lib_talk_001",
      "cat": "talk",
      "label": "麻烦让一下，我过去，谢谢",
      "file": "talk/lib_talk_001.wav",
      "sha256": "…64 位…",
      "size": 67558,
      "free": true
    }
  ]
}
```

字段约束（客户端会校验，不合格条目直接跳过）：

- `id`：`[A-Za-z0-9_-]{1,64}`，同时作为本地缓存文件名，**不可含路径分隔符**
- `file`：相对仓库根的路径
- `sha256`：必须 64 位；下载后与字节数一起校验，不符不落盘
- `cat`：`talk` / `lock`（决定在界面上归到哪一栏）

## 版本历史

| 版本 | 内容 | 条数 |
|---|---|---|
| v3 | 喊话 50 + 锁车 100 | 150 |
| **v4** | 在 v3 基础上**新增**喊话 100 + 锁车 100（`lib_talk_*` / `lib_lock_*`） | **350** |

### v4 新增的 200 条

- **喊话 100 条**（`lib_talk_001`–`lib_talk_100`）：10 组场景 × 10 条 —— 让行借过、倒车挪车、
  临时停靠、安全提醒、感谢礼貌、夜间雨天、小区学校医院、应急故障、搞怪趣味、车队自驾。
  8 种中文音色（含东北话、陕西话），语速按场景 0%~+14%。
- **锁车音效 100 个**（`lib_lock_001`–`lib_lock_100`）：10 个音效族 × 10 变体 ——
  双短音、三连音、低沉闷响、门铃叮咚、和弦、滑音、机械锁舌、电子提示、节奏音、鸟鸣。`label` 形如「双短音01」。

两条统规格：**16 kHz / 单声道 / 16 bit PCM WAV**，峰值统一归一化到 0.84（约 −1.5 dBFS），
首 4 ms attack、尾 6 ms release，避免功放起停爆音。喊话 887–2565 ms，锁车 426–950 ms。

## 音频来源与版权

- **喊话**：微软公开 TTS（edge-tts）合成，**文案为本项目原创**（参考公开交通安全标语与常见礼貌用语的
  表达方式，不复用商标、影视台词或特定 IP 原声）。
- **锁车音效**：纯程序化合成（正弦 / 方波 / 三角 / 金属泛音 / 噪声脉冲 / 扫频 / 和弦），无外部采样素材。

**未抓取、未转码、未再分发任何第三方音频文件。** 因此这里的「还原度」指听感风格与节奏对齐市面常见款，
不是文件级复制。仓库内音频可自由用于本项目的测试与调试。

## 新增条目的流程

1. 把 WAV（16 kHz / mono / 16 bit）放进 `talk/` 或 `lock/`；
2. 算 `sha256` 与字节数，往 `manifest.json` 的 `clips` 里追加一条；
3. `version` +1，并把同一份内容另存为 `manifest-v{新版本}.json`；
4. 提交。客户端会自动探测到新版本，无需改 App。
